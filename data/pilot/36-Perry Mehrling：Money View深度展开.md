## 零半、四种价格（The Four Prices of Money）

### 🟢 核心命题

Money View 分析任何东西，都从**四种价格**开始。这是整个框架的起点——不先搞懂这四个价格，后面所有概念都会跑偏。

| 价格 | 含义 | 简单说 |
|------|------|--------|
| **Par（平价）** | 一块钱在任何层级都必须等于一块钱 | "一块钱就是一块钱" |
| **利率** | 今天的一块钱 = 未来的几块钱？ | "钱的时间价格" |
| **外汇** | 一种货币 = 几种另一种货币？ | "钱的空间价格" |
| **物价水平** | 一块钱 = 多少实际商品？ | "钱的购买力" |

### 🔴 为什么 Par 是最重要的？

Par 看似废话——"一块钱等于一块钱"，这不就是定义吗？

**不是。Par 是一种制度维持，不是自然规律。**

在正常运行的金融体系里：
- 你的银行卡余额 100 块 → 去 ATM 取，就是 100 块现金
- 货币市场基金 1 份 → 赎回就是 1 美元
- 银行存款 → 可以 1:1 换成美联储负债（现金/准备金）

但危机时，**Par 会被打破**：
- 北岩银行挤兑：存款人发现取不出钱了——存款 ≠ 现金了
- 2008 年 Reserve Primary Fund "break the buck"：货币市场基金净值跌破 $1——基金份额 ≠ 1 美元了
- 恒大理财产品：承诺到期兑付 → 实际兑付打了骨折——理财 ≠ 它承诺的价值了

### 🔴 Par 跟货币层级的关系

**层级收缩的本质，就是底层不再能以 Par 兑换顶层。**

正常情况下，底层（银行存款）和顶层（美联储负债）之间有一个 1:1 的兑换承诺。当这个承诺被打破时——不管是因为银行真的没钱了，还是因为大家**不相信**银行有钱了——层级就收缩了。

你在 W2 学的挤兑，在 W4 学的明斯基时刻，在 W6 学的 Repo 挤兑——**本质上都是 Par 的崩溃**。

> "All banking is a swap of IOUs." —— Mehrling
>
> 所有银行活动，就是各种"欠条"之间的交换。而 Par 就是保证这些欠条能 1:1 交换的规则。规则一破，游戏结束。

## 一、弹性 vs 纪律（Elasticity vs Discipline）

### 🟢 核心命题

金融系统有两个永恒的、互相拉扯的力量。理解这对概念，你就理解了危机为什么会"周期性"发生。

```
    弹性（Elasticity） ←→ 纪律（Discipline）

    信用扩张            信用收缩
    底层变宽            顶层约束
    繁荣时期            衰退时期
    "信用看起来像钱"     "信用不像钱了"
    金字塔膨胀          金字塔收缩
```

### 🔴 这对概念怎么运作？

**弹性**：金融体系会不断创造新的"类货币"信用工具（存款、商业票据、MBS、Repo 份额）。每创造一种新的信用工具，金字塔的底层就变宽一点。繁荣时期，这些底层信用**用起来跟真正的钱没区别**——你刷卡、转账、投资，没人问"这个信的底层资产是什么"。

**纪律**：但金字塔的顶层（黄金 / 美联储负债）的数量是**有限的、有约束的**。不管底层膨胀到多大，顶层就那么多。当底层信用太多、顶层不够用的时候——纪律就来了。

### 🔴 危机的本质：弹性 → 纪律的切换

```
繁荣期（弹性主导）：
  底层信用扩张 → 大家觉得"这些都跟钱一样" → 继续扩张 → 
  杠杆越来越高 → 期限越来越错配 → ...

转折点（某个触发事件）：
  资产价格下跌 / 某家大机构违约 / 政策收紧

收缩期（纪律主导）：
  大家突然意识到"这些不是钱" → 冲向顶层 → 
  底层信用工具被抛售 → 价格暴跌 → 更多人意识到"这些不是钱" →
  正反馈循环 → 明斯基时刻
```

**你在 W4 学的明斯基时刻，用弹性/纪律的语言来说就是：系统从弹性主导突然切换到纪律主导的那个瞬间。**

### 🔴 央行在这对矛盾中的角色

央行不是消灭弹性，也不是消灭纪律——**央行是在两者之间寻找平衡**：

- 弹性太多（泡沫）→ 加息，增加纪律
- 纪律太多（危机）→ 降息/QE，注入弹性

但央行的问题是：**加息容易降息难**。就像 Keynes 说的："政府减缓经济像踩刹车，刺激经济像推绳子。"

## 二、货币的层级（The Hierarchy of Money）

### 🟢 核心命题

货币不是单一的东西。它是一个**层级结构**，每一层的"钱"对上一层都是一种**支付承诺**。

### 层级结构（从顶到底）

```
    ┌──────────────────────────────┐
    │  黄金（历史上）               │  ← 最终支付手段，不需要别人兑现
    │  美联储负债（准备金+现金）     │  ← 现代的最终支付手段
    ├──────────────────────────────┤
    │  国债（Treasury）             │  ← 以美联储负债计价，极高流动性
    ├──────────────────────────────┤
    │  银行存款                     │  ← 银行承诺你可以1:1换成现金
    ├──────────────────────────────┤
    │  货币基金份额                 │  ← 承诺1:1赎回
    ├──────────────────────────────┤
    │  商业票据（Commercial Paper）  │  ← 企业承诺到期还钱
    ├──────────────────────────────┤
    │  你的银行卡余额               │  ← 银行对你的负债
    └──────────────────────────────┘
```

### 🔴 关键理解

你在 W2 学过部分准备金制度。现在把它放到层级里看：

- 你的银行卡余额是**银行对你的负债**（银行欠你的钱）
- 银行的准备金是**央行对银行的负债**（央行欠银行的钱）
- 层级越往下，承诺越多，但**最终支付手段**只有一种

**危机的本质，就是层级的收缩。**

正常情况下，你拿银行卡刷卡买东西，没人会问"这家银行的准备金够不够"——因为大家默认银行存款 = 现金。但一旦有人开始怀疑，层级就会**向上收缩**：大家只认最顶层的东西，底层的"钱"突然就不被接受了。

你 W2 学的北岩银行挤兑，就是这个过程的具象化：存款人发现银行可能没法把存款变成现金，于是冲向银行要真钱。

### 🟢 Mehrling 的原话

> "Money is a social relation. It is a promise to pay. The question is: a promise to pay *what*?"

货币是一种社会关系——是**支付的承诺**。问题是：承诺支付*什么*？答案是：承诺支付层级上更靠近顶端的东西。

### 🔴 这跟你已经知道的东西的关系

你在 W4 理解的恒大暴雷，本质上是恒大发行的各种信用工具（商业票据、理财产品、供应商欠款）从层级中**被踢出去了**——没人再接受这些"承诺"。恒大欠供应商的钱，本来在供应商的账上是"资产"，但一旦没人承认它是钱，这些资产瞬间归零。

**层级理论给了你一个分析框架：任何危机，都是某种"钱"从层级中跌落的过程。**

## 三、银行与货币创造（Banking & Money Creation）

### 🟢 核心命题

**贷款创造存款，不是存款创造贷款。**

你在 W2 已经理解了这个。现在用 Mehrling 的方式把它写得更精确。

### 🟢 用 T 型账户看货币创造

假设银行给企业发放一笔 100 万的贷款。银行的资产负债表变化如下：

```
银行的资产负债表：

资产（Assets）              负债（Liabilities）
───────────────────         ───────────────────
+100万  对企业贷款          +100万  企业存款（新创造的）
```

**注意：存款是在贷款发放的瞬间被创造出来的。** 银行不需要"先有存款才能放贷"。

### 🔴 那准备金呢？

你 W2 学过部分准备金制度。现在的问题是：如果准备金只有 10%，银行怎么应付清算？

答案是两个层面：

1. **个体银行层面**：如果放贷太多导致准备金不够，银行可以去**同业市场**借准备金，或者从**美联储贴现窗口**借
2. **系统层面**：整个银行体系不需要每个银行都hold满准备金，因为**一家银行的贷款会变成另一家银行的存款**，准备金只是在银行之间转移，总量不变

### 🟢 约束在哪里？

如果贷款创造存款没有上限，银行为什么不无限放贷？

Mehrling 的回答：**约束不是准备金，是清算。**

- 银行A给企业X放贷100万 → X的账户多了100万存款
- X用这100万支付给在银行B开户的企业Y
- 银行A必须把100万准备金转给银行B
- 如果银行A没有足够准备金，它就会在清算中失败

**所以约束是：银行必须确保在每天的清算中，它有足够的准备金支付给其他银行。**

### 🔴 这跟"发起-分销"模式的关系

你在 W2 自己推导出的那个洞察——"银行给年入1.4万的人贷50万，不是因为信他还得起，是因为能卖给别人"——现在可以用清算约束来理解：

- 如果银行**持有**贷款到到期，它需要关心借款人能不能还（信用风险）
- 如果银行**卖掉**贷款（证券化），它就不需要关心了——因为它把信用风险转嫁给了买家
- 但银行仍然关心**清算约束**：它需要在每天清算时有足够准备金

这就是 W3 我们讲的"风险转嫁"在资产负债表层面的精确表达。

## 四、美联储与最后做市商（The Fed & Dealer of Last Resort）

### 🟢 核心命题

美联储不是"控制货币供应量"的开关。它是金融体系的**最后做市商**（dealer of last resort）。

### 🟢 传统教科书的错误

你 W2 学过教科书里的"货币乘数"模型：央行注入准备金 → 银行多倍放贷 → 货币供应量扩张。

Mehrling 说这是**因果倒置**：

- 不是"准备金 → 贷款"
- 而是"贷款需求 → 银行放贷 → 银行需要准备金 → 央行被迫提供"

🟢 **央行的准备金供给是被动的**——银行体系需要多少，央行就必须给多少，否则利率会失控。

### 🟢 美联储的两种操作

#### 1. 公开市场操作（OMO）

- 美联储买入国债 → 向市场注入准备金
- 美联储卖出国债 → 从市场抽走准备金
- **目的不是控制准备金数量，而是控制联邦基金利率（fed funds rate）**

🟡 你可以理解为：美联储是在**给准备金定价**，而不是在**控制准备金的量**。

#### 2. 贴现窗口（Discount Window）

- 银行可以直接向美联储借钱（用优质资产做抵押）
- 利率通常比联邦基金利率高 0.5%（惩罚性利率）
- 这就是 Bagehot 规则的制度化

### 🔴 Bagehot 规则（1873年）

🟢 19世纪英国经济学家 Walter Bagehot 在《伦巴第街》（Lombard Street）中提出的危机应对原则，至今仍是央行操作手册：

> "在危机中，央行应该：
> 1. **自由放贷**（lend freely）
> 2. **但只收优质抵押**（against good collateral）
> 3. **收取惩罚性利率**（at a penalty rate）"

这三条逻辑是连贯的：
- 自由放贷 → 防止流动性枯竭
- 优质抵押 → 防止道德风险（不能让经营不善的银行白拿钱）
- 惩罚性利率 → 鼓励银行只在真正需要时才来借

### 🔴 "Dealer of Last Resort" vs "Lender of Last Resort"

这是 Mehrling 最重要的理论贡献之一：

- **传统说法**：央行是"最后贷款人"（lender of last resort）
- **Mehrling 修正**：央行是"最后做市商"（dealer of last resort）

区别在哪？

- **贷款人**：有人来借，我借给他。是**被动的**。
- **做市商**：市场上没人愿意买的时候，我来买；没人愿意卖的时候，我来卖。是**主动提供流动性**的。

🟢 2008年危机中，美联储不只是通过贴现窗口借钱给银行，它直接**买入**市场上没人要的东西（MBS、商业票据、AIG的CDS）。它是在做市，不是在放贷。

### 🟢 做市商层级（Market Maker Hierarchy）

"最后做市商"不是央行独有的角色——**货币层级的每一层都有自己的做市商**：

```
    层级              做市商
    ──────────        ──────────
    黄金 → 货币        央行
    货币 → 存款        银行体系
    存款 → 证券        证券商（dealers）
```

每个做市商的职责都是**让下一层的东西能以 Par 兑换上一层的东西**：
- 银行保证你的存款能 1:1 换成现金
- 证券商保证证券能按市场价换成存款

**央行是唯一一个不只为短期利润做市的机构。** 其他做市商在利润不够时会退出（"不做市了"），央行不行——因为它对最终危机负责。

所以当所有其他做市商都退出时（2008年证券商集体不接盘MBS），央行必须顶上——这就是"dealer of last resort"的真正含义：**最后一个还在做市的人**。

### 🔴 这跟恒大的关系

恒大危机中，中国政府的选择是**不做最后做市商**——让恒大违约，让理财产品兑付失败，让购房者承受损失。

对比2008年美国：美联储买入MBS，财政部注资AIG。

两种选择的后果完全不同。这解释了为什么W4恒大的传导链会一路延伸到162万套烂尾楼——因为没有最后做市商来吸收这些"没人要的资产"。

## 五、回购市场（Repo）与影子银行—— 金融体系的暗管

### 🟢 核心命题

**回购市场是现代金融体系最大的"暗管"。大多数人不知道它的存在，但它决定了流动性是否充足。**

### 🟢 影子银行（Shadow Banking）是什么？

🟢 精确定义：**持有短期、低风险资产的实体，用这些资产作抵押从货币市场获取流动性，再把流动性提供给银行体系。**

关键特征：
- 不是传统银行（没有存款许可证、不受银行监管）
- 持有"安全"资产（国债、高评级MBS等）
- 通过 Repo 市场借入短期资金
- **规模超过传统银行体系**

你可以把影子银行理解为**"没有银行存款牌照，但做着类似银行的事"的机构**——投行、货币基金、SIV（结构性投资载体）、对冲基金。

### 🔴 影子银行跟弹性/纪律的关系

影子银行是**弹性扩张的主要引擎**：
- 繁荣期：大量安全资产被创造出来（MBS、ABS等）→ 影子银行用它们作抵押借入更多资金 → 信用扩张 → 弹性增加
- 危机时：这些"安全资产"不再安全 → 抵押品价值缩水 → haircut 上升 → 影子银行被迫抛售 → 弹性瞬间变成纪律

**影子银行是金融系统里最弹性、也最脆弱的部分。**

### 🟢 什么是 Repo？

Repo（Repurchase Agreement，回购协议）= **有抵押的隔夜借款**。

运作方式：
1. 机构A持有国债（或其他证券）
2. 机构A把国债"卖"给机构B，同时承诺第二天以略高的价格"买回来"
3. 价格差 = 利息（回购利率）

```
今天：A把国债给B，B给A $100
明天：A把国债从B拿回来，A给B $100.02
$0.02 = 隔夜利息（年化约 5%）
```

### 🔴 为什么这很重要？

因为 Repo 的本质是**用证券当抵押品来创造"类货币"**。

回到货币层级：
- 国债在层级的高处
- 通过 Repo，国债变成了**准货币**——因为它可以随时换成现金
- 大量的短期融资（包括投行的日常运营）依赖 Repo 市场

🟢 数据：美国 Repo 市场日均交易量超过 **1 万亿美元**。

### 🔴 2008 年危机的本质：Run on Repo

你 W2 学过银行挤兑——存款人同时冲向银行要现金。

Repo 挤兑是同样的逻辑，只是主体不同：
- 银行挤兑：散户 → 银行
- Repo 挤兑：机构投资者 → 影子银行

2008 年发生了什么：
1. 影子银行（投行、SIV等）用 MBS 做抵押在 Repo 市场借钱
2. 当 MBS 价格下跌，Repo 贷款方要求更高的**折扣**（haircut）——比如原来 $100 的 MBS 借 $98，现在只能借 $80
3. 影子银行被迫**追加抵押品**或**抛售资产**
4. 抛售 → 价格进一步下跌 → haircut 进一步提高 → 被迫抛售更多
5. 这就是 Repo 市场的**死亡螺旋**

🔴 Mehrling 的原话：

> "The financial crisis of 2007-2009 was not a run on banks. It was a run on repo."

### 🔴 这跟你已经知道的

W4 的明斯基时刻说的是：投机性融资和庞氏融资在利率上升或资产价格下跌时崩溃。

Repo 挤兑就是明斯基时刻的**具体机制**：
- 影子银行用短期 Repo 资金（隔夜借款）来持有长期资产（MBS）→ 这是典型的**期限转换**
- 一旦资产价格下跌，haircut 上升，短期融资断裂 → **庞氏融资崩溃**

你把 W4 的抽象理论和 W6 的具体机制放在一起，就得到了一个完整的危机模型。

## 六、欧洲美元（Eurodollar）—— 美元的世界体系

### 🟢 核心命题

**美元不只是美国的货币。它是一个全球体系，大部分美元在美国境外创造和流通，不受美联储直接控制。**

### 🟢 什么是欧洲美元？

🟢 定义：**美国境外的美元存款**。

- 伦敦的一家银行持有的美元存款 → 欧洲美元
- 开曼群岛的一家基金持有的美元账户 → 欧洲美元
- 中国出口商收到的美元货款存在新加坡银行 → 欧洲美元

"欧洲"不是说只在欧洲——它指的是**美国境外**的任何美元。

### 🔴 为什么这个概念重要？

因为你 W2 理解的部分准备金制度，在**欧洲美元体系中同样运作**：

- 境外的美元银行也在用美元存款发放美元贷款
- 它们也在创造"欧洲美元"——但这些美元**不在美联储的资产负债表上**
- 全球欧洲美元体系的规模在 2008 年前估计超过 **10 万亿美元**

🔴 这意味着：美联储只控制美国境内的美元基础货币，但**全球美元的总量远超美联储的控制范围**。

### 🟢 欧洲美元银行体系

你可以把欧洲美元银行理解为：

```
    美联储（美国境内美元）
        │
        │ 控制不了
        ▼
    伦敦/新加坡/开曼/上海...
    境外美元银行网络
        │
        │ 也在放贷、也在创造存款
        ▼
    全球美元 = 境内美元 + 欧洲美元
```

### 🔴 危机时的问题

正常情况下，欧洲美元体系自转。但危机时：

1. 境外美元银行需要美元流动性（存款人要取美元）
2. 它们不能直接从美联储拿钱（因为不是美国银行）
3. 它们只能通过**外汇互换**（FX swap）来获取美元
4. 但如果全球都在抢美元，互换市场的成本飙升

🟢 2008 年和 2020 年，美联储被迫开通**货币互换额度**（swap lines），直接给欧洲央行、日本央行、英国央行等提供美元，让它们再借给各自的境内银行。

🔴 这意味着：美联储事实上成为了**全球的最后贷款人**——尽管它的法定职责只限于美国。

### 🔴 这跟你的公众号选题的关系

你写过很多关于"制度荒诞"的文章。欧洲美元体系本身就是一个巨大的制度荒诞：

- 全世界用美元做生意，但美元不由世界管理
- 美联储只对美国国会负责，但它的决定影响全球几十亿人
- 当一个土耳其企业借了美元债务、里拉暴跌、还不起——追根溯源，这可能跟美联储加息有关，但这个土耳其企业没有任何渠道向美联储表达诉求

🔴 这就是 Mehrling 说的：货币层级在全球尺度上也是一样的——**顶层是美联储负债，底层是各种"美元承诺"**。危机时，底层跌落。

## 七、统一图景

现在把你在这七个模块学到的东西画成一张图：

```
                    美联储
                      │
              最后做市商（模块4）
           唯一不为短期利润做市的机构
                      │
         ┌────────────┼────────────┐
         ▼            ▼            ▼
     境内美元     货币层级     欧洲美元
    （模块3）     （模块2）    （模块6）
         │            │            │
    贷款创造存款   顶层=最终支付  境外美元网络
    清算约束       底层=私人承诺  不受美联储控制
         │            │            │
         └────────────┼────────────┘
                      ▼
               做市商层级（模块4新增）
        央行→银行→证券商，每层保证Par兑换
                      │
                      ▼
               回购市场+影子银行（模块5）
            证券→准货币→弹性扩张引擎
            危机时=弹性→纪律的切换通道
                      │
                      ▼
               弹性 vs 纪律（模块1新增）
        繁荣=弹性扩张（底层变宽）
        危机=纪律主导（冲向顶层）
        央行=两者之间的平衡器

统一规律：
  繁荣期：弹性扩张 → 底层信用看起来像钱（Par维持）
  转折点：触发事件 → 做市商退出 → Par动摇
  危机期：纪律主导 → 层级收缩 → Par崩溃
  兜底：央行做最后做市商 → 注入弹性 → 恢复Par
```

### 用这个框架重看你已经学过的案例

| 案例 | 用 Money View 重新解释 |
|------|----------------------|
| **北岩银行挤兑**（W2） | 存款（层级底层）→ 不被信任 → Par 动摇 → 冲向顶层（现金） |
| **恒大暴雷**（W4） | 恒大的各种"钱"（商票、理财、欠款）从层级中跌落，Par 崩溃 |
| **NINJA 贷款**（W2） | 底层信用被包装成高层级证券（MBS评级AAA），但底层是烂的——弹性过度扩张的产物 |
| **瑞幸复活**（W3） | 信息透明恢复了市场信心 → 瑞幸的股票重新被接受为"有价值的东西" |
| **蜜雪冰城加盟**（W2） | 品牌方把自己放在了层级的上层（收供应链利润），加盟商承担底层的风险 |
| **2008 年危机** | 影子银行 Repo 挤兑 → 证券商停止做市 → 弹性→纪律切换 → 央行做最后做市商兜底 |
| **货币市场基金 break the buck** | Par 被打破的最直观案例——$1 的基金份额不再等于 $1 |
