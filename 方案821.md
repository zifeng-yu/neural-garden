数据建立 - src.indexer
流程：
遍历数据文件 -> 单个文件 -> 进行chunk（使用了langchain md header + RecursiveCharacterTextSplitter（参数500，over=100) )

每个chunk -> llm -> knowledgeUnit(title + summary + keywords) 可能chunk提炼失败存在 1chunk -> 0knowledgeUnit

chunk + knowledgeUnit.title(提炼不出的不处理) -> llm -> concepts <=10个

concepts -> 内部归一 -> 外部归一
内部归一：doc下所有的concepts -> 相似度矩阵 -> 阈值0.2 -> concept pairs
        -> build graph -> 获取所有连通分量 connected_components
        -> 每一个连通分量 + 涉及的chunk文本 -> llm -> 获得归一结果

外部归一：如果是第一篇文章，外部归一执行不了 因为chroma-concept没有数据
        使用内部归一后的数据进行
        chroma-concept 相似度搜索（此时这篇doc concept还没有入库）
        -> 搜索到的是其他doc产生的概念 -> 阈值0.2 top-k =1
        -> 新概念+chunk文本（内存）， 相似概念+chunk文本(查库) -> llm
        -> 0个或多个相似概念 多个取第一个 

save_sqlite -> doc doc_chunk doc_chunk_knowledgeUnit doc_chunk_concept
upsert_chroma -> concept knowledgeUnit

建立chunk内 concept relation -> chunk文本 + concepts -> llm
    -> concept的关系 edge 属性 -> save concept_relation（可能冲突，冲突返回原id） relation_evidence
*chunk、doc外部 concept relation 暂时不建立
