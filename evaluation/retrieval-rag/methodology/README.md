# 检索与 RAG 评估方法

对同一问题比较 vector、BM25、RRF hybrid，分开评价检索证据与生成回答。

| 指标或检查项 | 定义 | 已有情况 |
|---|---|---|
| Hit@3 | Top3 至少含一个可接受证据片段记为 1，否则为 0；按有答案问题求平均 | 原始结果已记录 |
| MRR@3 | Top3 第一个可接受证据的名次为 r，得分 1/r；未命中为 0 | 原始结果已记录 |
| 来源命中 | 最终 sources 是否包含可接受证据；与候选命中分开检查 | results.jsonl 有 source_hit |
| 引用编号合法 | 每个 claim 引用必须属于实际 sources | 历史审查已核对 |
| 断言忠实与完整 | 原文是否支持每项断言、限定词和因果关系 | report.md 有人工判断，未形成统一评分 |
| 拒答行为 | 无证据时拒答，有证据时避免过度拒答 | 有正反案例，未统计总体比例 |
| 耗时 | 检索耗时与回答耗时分别记录 | 仅单批测量，不作为服务性能分位数 |

原实验每路 candidate_k=10，最终 top_k=3，RRF 常数 60，原文预算 3000 字符。同题三个模式复用实际召回候选，调用真实原文查询和模型回答；固定候选输入用于控制比较，不是模拟模型答案。

有答案回归题 q01–q04、新增有答案题 q06、无答案题 q05/q07 分开统计。无答案题不进入 Hit/MRR 分母。预填 gold 与事后发现的等价证据分开报告，不改写原始 cases.jsonl。

q01 事后补入 chunk4、chunk5；q06 事后补入 chunk24、chunk26。这是历史审查中的标注订正，不是事前冻结数据。数据中的 holdout 字段不能证明这些问题未被查看或用于调参。

引用编号正确不等于回答语义正确。当前证据不足以证明某种检索在一般问题上全面优于其他方式。
