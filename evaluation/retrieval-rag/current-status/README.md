# 检索与 RAG 现状

更新日期：2026-10-11。根据当前实现与已归档结果总结，本次未重跑真实检索或模型问答。

当前支持 Chroma 向量检索、ES BM25 和 RRF 混合检索，默认仍是向量检索。RAG 在检索后读取 SQLite 原文、组织引用来源，再生成回答；HTTP API 调用默认向量 RAG。检索结果与回答生成的评估需要分开看。

已有 7 题、三模式共 21 条历史对照，保存了候选、融合排名、原文、回答和耗时。有答案回归题的 Hit@3 为 vector 3/4、BM25 4/4、hybrid 4/4；原标注 MRR@3 为 0.5833、0.7500、0.5417。它说明局部证据覆盖改善，不能证明混合检索整体最优。

已发现的回答问题包括遗漏“超过”限定词、有足够原文却拒答，以及引用只支持部分条件。引用编号合法不代表语义完整或忠实；这些问题尚无当前版本真实复测结果。

评估仍依赖小样本，部分 gold 经事后订正，未保存完整语料快照；历史脚本硬编码旧路径且有加载副作用，暂不具备直接重复运行的能力。后续应先整理评估入口、固定语料和配置，保持原标注与订正标注分离，再对失败案例做回归。
