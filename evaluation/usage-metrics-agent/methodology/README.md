# 指标 Agent 评估方法

业务统计量与 Agent 质量指标分开。业务量是搜索次数、零结果搜索次数和文档点击次数；它们不是 Agent 正确率。

当前工具为 query_popular_queries、query_zero_result_queries、query_popular_documents，统一接受 start_date/end_date_exclusive，不接受 metric 或 SQL 参数。SQL 在 feedback_analytics.py，工具负责日期校验与响应组装。

| 评估项 | 判定口径 |
|---|---|
| 工具选择 | 用户问题对应正确的三工具之一 |
| 日期参数 | 上海日期，起始含当天、结束不含当天；“1日至7日含”转为 [10-01,10-08) |
| 缺参澄清 | 没有明确指标或日期时询问，不自行编造参数 |
| 追问继承 | 同一期间继承前轮日期，切换指标时选择对应工具 |
| 统计正确 | 返回 Top5、排序和次数与固定样本 SQL 期望一致 |
| 回答保真 | 不改数字、不编造文档标题，不把次数说成人数或点击率 |
| 空结果和异常 | 空结果成功返回；缺库/缺表异常不得伪装成“无记录” |

后续可按用例类型计算选工具、选参、澄清和数值保真的通过率。当前测试验证工具契约，历史日志验证旧版 Agent 行为；两类证据不能混成当前三工具 Agent 的整体通过率。
