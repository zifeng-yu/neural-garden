# 指标 Agent 现状

更新日期：2026-10-11。当前实现、离线测试与历史模型运行分开总结，本次未调用真实模型。

当前入口是 src.usage_metrics_agent_cli。指标查询已重构为 query_popular_queries、query_zero_result_queries、query_popular_documents 三个独立工具；只接受起始日期和不含当天的结束日期，SQL 与工具响应组装分离。

合成数据包含 11 条搜索记录、13 条反馈事件。当前工具与 SQL 的 27 项离线测试通过，覆盖日期边界、Top5、参数限制、空结果和缺库/缺表异常。它们证明工具接口及统计行为，不证明模型能够正确选择新版三个工具。

三份历史模型日志使用旧版 query_usage_summary 单工具。热门词首问及零结果追问的数值和日期继承符合预期；缺参场景会澄清；真实库点击查询得到空结果。原自述“没接入”的说法由真实库日志补充纠正。零结果回答将 3 个词分组说成“记录共3项”，存在把分组数与搜索次数混淆的表达风险。

当前缺少重构后真实模型的选工具、多轮追问、缺参澄清复测，以及真实库非空数据核验。后续应使用已有三个场景调用当前入口，保存独立日志，逐项对照工具名、日期、次数和回答措辞；旧日志继续作为历史证据。
