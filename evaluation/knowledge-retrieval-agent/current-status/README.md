# 知识检索 Agent 现状

更新日期：2026-10-11。根据当前实现与历史运行记录总结，本次未重新调用模型。

当前入口是 src.knowledge_retrieval_agent_cli，使用 LangGraph 和会话状态，提供 search_knowledge 向量检索及 read_chunk 原文读取工具；回答规则由调用方提供 SYSTEM_PROMPT。多轮追问可在同一 thread 中保留上下文。

已整理 4 个完整历史场景、1 个缺少首问的追问片段，并保存 4 块实际读取的原文证据。集合查重和狐狸型专家场景有工具调用、原文引用及出处追问记录；普通问候未调用工具。

主要问题是无资料问题的追问转向无关材料，以及将原文描述扩大成未经支持的因果解释。NBA 示例还出现错误的时间判断。因此不能把整批场景标记为全部通过，也没有统一口径的正确率。

场景是在查看结果后整理的，没有事前冻结；历史记录缺少完整批次、提示词版本和语料快照。现有图执行测试能验证状态和节点行为，不能替代真实模型选工具、引用和拒答质量评估。后续优先补齐不完整用例，按当前入口复测无答案追问与因果忠实性，并记录每轮工具轨迹。
